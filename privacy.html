Privacy policy

Aisha is a private, self-hosted assistant used only by its owner. It is not a public service.

What data is accessed

With the owner's authorization, Aisha accesses the Gmail account dedicated to it: it can read messages and create drafts or send messages (always after the owner confirms).

How data is used and stored

Data is used only to carry out the owner's requests. Authorization tokens are kept in the operating system's secure keychain on the owner's computer. Email content is not sold, shared with third parties, or used for advertising.

Revoking access

The owner can disconnect the account at any time from Aisha's settings or from the Google Account permissions page, which deletes the stored tokens.

Google API Services

Aisha's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
